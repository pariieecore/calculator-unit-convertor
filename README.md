# Menu-Driven Calculator and Unit Converter

## About the Project
This is a simple Python-based calculator and unit converter. It allows users to perform basic mathematical operations and convert different units through a menu-driven command-line interface.

The program keeps running until the user selects the Quit option.

## Features
- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Kilograms to Pounds conversion
- Input validation to handle incorrect inputs
- Handles division by zero
- Continuous menu using a while loop

## Technologies Used
- Python 3
- VS Code / Any Python IDE

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Unit Conversions

| Conversion | Formula |
|---|---|
| Kilometers to Miles | km × 0.621371 |
| Celsius to Fahrenheit | (C × 9/5) + 32 |
| Kilograms to Pounds | kg × 2.20462 |
